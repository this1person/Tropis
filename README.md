# Tropospheric NO₂ Global Changes Before, During, and After COVID-19

## Overview
This project investigates global changes in tropospheric Nitrogen Dioxide ($\text{NO}_2$) column density before (2018–2019), during (2020–2021), and after (2022–2024) the COVID-19 pandemic across 12 major world metropolitan regions using **Sentinel-5P TROPOMI (COPERNICUS/S5P/OFFL/L3_NO2)** data via Google Earth Engine.
